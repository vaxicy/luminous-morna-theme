## Features

- Two themes in one extension: **Luminous Morna Theme Light** and **Luminous Morna Theme Dark**.
- Warm neutral canvas - cream paper in light mode, deep olive in dark mode.
- One teal accent drives the cursor, badges, buttons, active tab and breadcrumbs.
- Muted syntax palette (plum, moss, gold, slate) that stays easy on the eyes.
- Scrollbars, indentation guides and selection colours tuned per variant.

## Install

1. Open the Extensions view in VS Code (`Ctrl+Shift+X`).
2. Search for **Luminous Morna Theme** and install it.
3. Run `Preferences: Color Theme` (`Ctrl+K Ctrl+T`) and pick
   **Luminous Morna Theme Light** or **Luminous Morna Theme Dark**.
