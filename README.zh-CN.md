## 特点

- 一个扩展装两套主题：**Luminous Morna Theme Light** 和 **Luminous Morna Theme Dark**。
- 底色是暖调的：浅色像米白纸，深色是深橄榄，都不是纯灰或纯黑。
- 全主题只用一个青色主色，光标、徽标、按钮、活动标签、面包屑都跟着走。
- 语法配色压低饱和度（梅子紫、苔绿、暗金、灰蓝），关键词能跳出来但不刺眼。
- 滚动条、缩进辅助线、选区色明暗两套分别调过。

## 配色

| 用途 | 浅色 | 深色 |
|---|---|---|
| 编辑器底色 | `#FCFBED` | `#2A2919` |
| 前景文字 | `#2D2C25` | `#F1F0E9` |
| 主色 | `#1D7D75` | `#25A096` |
| 选区 | `#BED8CB` | `#294A3C` |

## 安装

1. 在 VS Code 里打开扩展面板（`Ctrl+Shift+X`）。
2. 搜索 **Luminous Morna Theme** 并安装。
3. 按 `Ctrl+K Ctrl+T` 打开颜色主题列表，选 Light 或 Dark 版本。
